Screen Agent

Captures a screenshot every few seconds and uploads it to the cloud. Start/stop with one click.

Download for Windows Portable .exe

Windows 10 or 11, 64-bit. The installer adds a Start-menu shortcut and an uninstaller, and can start the app when you sign in.

Install

  1. Click Download for Windows.
  2. If Windows shows a blue “Windows protected your PC” box, click More info → Run anyway (this appears until the app is code-signed).
  3. Follow the installer, then launch Screen Agent.
  4. Fill in the bucket and keys if they aren’t already set, then press Start.

Uninstall

Settings → Apps → Screen Agent → Uninstall.
